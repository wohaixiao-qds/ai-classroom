## 0. 技术决策（基于调研定稿）

| 决策 | 结论 | 依据 |
|---|---|---|
| 播放器内核 | **reveal.js + @revealjs/react**，自定义主题套用已验证的设计 token | 官方 React 封装；fragment 机制天然支持「动画跟讲稿」 |
| 音画同步 | **事件驱动**：每句音频 `ended` → `Reveal.next()`（进下一 fragment/页） | 比 Slidev 时间轴方案简单可靠，暂停续播免费 |
| 断点续播 | 保存三元组 `(slideIndex, fragmentIndex, audioIndex)` | Slidev recording 机制的简化版 |
| 对话区 | **assistant-ui**（headless，接 FastAPI SSE） | 2026 事实标准；流式/Markdown/代码高亮白拿 |
| 组件/样式 | shadcn/ui + Tailwind v4 + Lucide | Linear 式深色 token 体系 |
| Agent 循环 | anthropic SDK 裸写 while 循环，`base_url` 指智谱 | 2~3 个工具的小 pipeline，框架是负资产 |
| TTS | edge-tts 起步，**抽象 provider 接口**，403/限流重试退避；兜底可切智谱语音 | 大陆 IP 403 风险实测确认 |
| 课件格式修正 | **CSL = JSON 为源（source of truth）**，Markdown 仅作人读预览导出 | LLM 输出 JSON 比解析 MD 少一层损耗；前后端类型统一 |
| UI 布局 | 左课件区（Slidev Seriph 式排版）+ 底部播放条（检查点在进度条打菱形）+ 右对话区（720px 扁平消息、`[1]` 引用指向课件页） | Coursera 字幕同步 + SetProduct 规范 + Perplexity 引用 |

## 2. 任务拆解（顺序执行，每步有验收）

### T1 · CSL schema 定义 + 第一课手写
- 定义 `csl.json` schema：`pages[]`，每页 `{type, 内容, 讲稿句[], fragments[], 动画编排, checkpoint?}`
- 把 harness 第一课内容手工写成 `courses/harness-01.csl.json`（P1 不做自动备课）
- ✅ 验收：JSON 通过 schema 校验，覆盖样例课件全部 7 页 + 自学版复述检查点

### T2 · TTS provider + 预生成音频
- 实现 provider 抽象 + edge-tts 实现（403 重试/退避）；CLI：`python scripts/tts_gen.py courses/harness-01.csl.json`
- 每句讲稿 → `audio/{page}-{sentence}.mp3`，时长写回 JSON
- ✅ 验收：第一课全部句子有音频，连续生成不崩；听感可接受（不好听则此处顺手试智谱语音对比）

### T3 · 前端骨架 + reveal 主题
- Vite + React + TS + Tailwind + shadcn/ui 初始化
- reveal.js 载入 CSL 渲染课件，主题套用已验证设计 token（石墨蓝/琥珀/Seriph 式排版），fragment 动画还原样例效果
- ✅ 验收：浏览器打开，第一课 7 页视觉≈样例，键盘可翻页

### T4 · 音画同步引擎 + 播放控制
- 同步：播放第 i 句音频 → `ended` → next fragment/页；页面到头翻页
- 控制：播放/暂停/上一页/重讲本页/倍速；检查点页自动暂停并弹复述输入框
- 断点：localStorage 存三元组，重进续播
- ✅ 验收：从封面全自动听到自测页，中途暂停再进能从断点续播

### T5 · 答疑接口 + 对话区
- 后端：`POST /api/chat`（SSE 流式），上下文=课件全文+当前页+相关笔记，智谱 Anthropic 兼容接口
- 前端：assistant-ui 接 SSE；提问自动暂停课件，答完「继续」按钮恢复；回答支持 `[1]` 式引用「课件第N页」
- ✅ 验收：讲第 3 页时提问「汽车类比再讲一遍」，回答引用课件内容且不跑题

### T6 · 复述批改闭环（P1 验收核心）
- 检查点弹层中提交复述 → 调 LLM 按教学风格批改（✅/⚠️/❌ + 🎯 精准版）→ 通过才解锁继续
- 学习轨迹落盘：哪页停留/提问/复述结果
- ✅ **P1 总验收：用它完整学完第一课，至少通过全部复述检查点**

## 4. 风险与预案
| 风险 | 预案 |
|---|---|
| edge-tts 大陆 403/限流 | T2 即实测；不行立刻切智谱语音（接口已抽象，半小时的事） |
| reveal.js 自定义动画表达力不够还原样例 | fragment + 自定义 CSS 动画类足够；真不够再评估纯自写播放器 |
| 智谱 GLM 答疑质量不达标 | T5 先测；不达标则答疑切 Claude（改环境变量），备课仍走智谱 |
| 范围蔓延 | 严格按 T1→T6，每个 T 完成即可用/可演示 |
