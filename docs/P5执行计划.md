## 一、已定决策(2026-11-02 用户拍板,不再议)

| 决策点 | 选择 | 理由 |
|---|---|---|
| 整体迁移成 DeepTutor 式书页 | **不做** | 迁移=重写音画同步/字幕/检查点/断点续播四块已验证引擎(全键在页/句模型上),抹掉差异化;若要的是 DeepTutor 产品本身,自托管它(Apache-2.0)是另一条路,与本项目无关 |
| 路线一:管线工程化 | **做** | 调研缓存/模板兜底/成本预估/操作日志,全是拆解文档已验证借鉴项,不改课件形态,单项 0.5~2 天 |
| 路线二:课件富化 | **做** | 保留页/句/TTS 主干,CSL 长出可选块维度(闪卡/图),喂现有复习闭环 |
| DeepTutor 产物形态 | 不照搬 | 它是无声图文块书页;「有声讲解」是本项目核心体验,块只做增量维度不是替代 |
| T0 在途 depends_on 实现 | **并行会话已完成**(`b0730e0`+`71f1288`) | 含实测全链;本轮独立单测复核校验机制(悬空 id/自依赖打回、合法落盘)通过,T0 关闭 |
| T5 闪卡形态 | **页级字段 `flash:[{front,back}]` + 课堂深链页内翻转卡** | 用户拍板;deep-link 天然成立、不加新工具、按页校验 |
| T6 图能力 | **mermaid,同意修订 P2「SVG 不做」+ 引入 mermaid 依赖** | 用户拍板;mermaid=文本可校验可降级,与自由 SVG 不同难度级 |

## 四、边界提醒(施工中必守)

- CSL 是「稳定的作者态契约」(P1 收口决策):T5/T6 字段改动需**同步三处**——`csl.ts` 手写类型、`csl_validator.py`、备课 prompt;课件 JSON 有 `apps/api/courses/`(源)与 `apps/web/public/courses/`(发布副本)两份,同步靠管线发布步骤,手改需两边一致(既有坑)
- 写类工具仍只进备课清单(铁律8);T2 的规划校验是 harness 确定性代码,不新增 LLM 工具
- 新依赖仅 T6 的 mermaid 一个,其余任务零新依赖
