## 2. 分层边界

- 前后端不互相 import。HTTP 通过生成的 API 契约连接，静态课件通过生成的 CSL 契约连接。
- 前端跨 feature 只依赖公共出口，共享能力放 `components`、`hooks`、`lib` 或 `utils`。
- router 保持薄层：校验输入、调用 service、转换传输结果；async 路由不直接阻塞。
- 一个 harness、多个独立循环；共用配置、客户端和 Trace，各自精选工具、上下文与终止条件。
- 编排、发布、复习排期和合法性检查由确定性代码负责；模型承担需要判断的工作。
- 开发时知识库只读。产品已有同步/笔记写回能力；验证必须使用临时目录，真实写回遵守用户确认流程。
- 修改定稿文档、样例、循环设计或既定产品语义，先说明范围并遵守 `AGENTS.md`。

## 3. 唯一契约来源

| 数据 | 唯一来源 | 生成路径 | 消费方式 |
|---|---|---|---|
| HTTP API | FastAPI/Pydantic OpenAPI | `pnpm -C apps/web gen-types` → `src/types/api.gen.ts` | 从生成产物派生类型 |
| 静态 CSL v1/v2 | `apps/api/app/schemas/csl.py` | `export_csl_schema.py` → 内存 OpenAPI → 现有 `openapi-typescript` → `src/types/csl.gen.ts` | 经 `src/types/csl.ts` 公共出口使用 |

静态文件不经 HTTP，不需要增加虚假业务路由来导出 schema。生成脚本不启动 API、不读取学习库、不调用模型。新增共享字段先改 Pydantic，再生成；`check-csl-types` 比较实际生成内容，漂移时失败，前端 `lint` 已串入此检查。`csl.ts` 中的 `UnitStat` 是前端视图结构，可以手写；`parseCourse` 仍是版本分派，不冒充运行时完整校验。

CSL v2 以顶层 `version: 2` 标记，`sections` 下包含七种块。旧 v1 模型保留给兼容读取/迁移；校验器拒绝新交付 v1。课程源与发布副本分开，管线负责发布同步；手工改课件时须理解两份文件关系。

## 4. 证据、学习状态与观测

- 新调研每点附 `source_id` 与逐字 `quote`；程序只对实际工具返回做正文快照、哈希和摘录定位。完整正文只留本地原料，课件只带摘录及邻近上下文。
- `meta.sources` 保留来源 ID，`meta.evidence` 保存要点证据，块的 `evidence_ids` 建立关联。编号合法、摘录命中、模型语义初审、人工正文审查是不同状态。
- 模型证据审查是单次服务，失败标为未审；原料判定不沿用为课件正文判定。未知证据引用或引用已标为不支持的要点会被拒绝。
- `scripts/audit_evidence.py` 默认只读导出正文与原文；`--model` 显式启用模型审查；`--reviews` 验证具名人工标签和内容哈希。未审返回 2，结构错误/不支持返回 1，全量人工确认才返回 0。
- 历史材料不伪造原文或评分，继续读写时标为待审。来源权威性、正文完整性、时效与模型裁判误判仍需人工校准。
- 学习结果读持久化 `learning_grades`，不依赖观测窗口；`source=test` 不推进学习状态。
- Trace 按 run_id 分执行与评估两阶段，保留失败/取消、版本和上下文哈希。观测结论不等于已校准准确率。

## 5. 开发与验证

```bash
./start.sh                  # API :8100；web :5273；日志 .run/
./start.sh api              # 单独重启 API
./start.sh web              # 单独重启前端
uv run --directory apps/api ruff check app tests scripts
uv run --directory apps/api mypy app
uv run --directory apps/api python -m unittest discover -s tests -v
uv run --directory apps/api python scripts/eval_agent.py --self-check
pnpm -C apps/web gen-types        # API 已启动时导出 HTTP 契约
pnpm -C apps/web gen-csl-types    # 无需起服务
pnpm -C apps/web check-csl-types
pnpm -C apps/web lint
pnpm -C apps/web build
```

`mypy app` 仍有历史基线错误，交付时报告实际结果及新增情况，不声称全库已清零。固定用例自检只证明检查器能区分参考与反例，真实模型效果需要固定输入的输出和人工标签。禁止通过替用户复述、调用真实写回或发布测试课程污染学习数据。

## 6. Git 与文档

Conventional Commits；按用户授权范围提交，不捎带同工作区其他任务的改动，不远程推送。完成任务更新 `AGENTS.md` 当前记录。README 只保留启动和有效入口；架构设计写实际约束及取舍，历史执行计划保持阶段语境，避免把已退役路径当作现状。
