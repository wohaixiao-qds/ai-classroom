## 一、已定决策(2026-08-24 对齐,不再议)

| 决策点 | 选择 | 理由 |
|---|---|---|
| 主线优先(2026-08-24 用户定) | **学新课主线提前串通**:找资料→备课→上课 | 原定找资料=P3;用户定调新课题走主线 |
| 找资料形态 | **独立循环**(M2a),原料落盘文件 | 调研与写作上下文分离;原料可人工审;合图纸「文件流水线协作」 |
| **框架双源合流**(2026-08-24 定稿) | 框架=源A 权威地图(官方文档/高星项目/教程目录)+源B 用户足迹(vault 待探清单,已有主题时);用户顺序优先、地图缺口显式标出、独特衍生保留;交人审 | 解「待探不全面」与「新模块无足迹」;学什么/什么顺序始终人拍板 |
| **一课=一个子题**(同上) | 备课输入=框架中的一个子题+位置感(前置子题),课件开场承接、结尾指向后续 | harness-01 粒度经真实学习验证;不是「一个主题一课」 |
| 来源有据(用户定,硬约束) | 原料每条要点必挂 source_id,落盘前程序校验,缺源打回;课件 meta.sources 带入 | 有据可查是全线哲学(答疑标[1][2]、A6 判有据) |
| MAX_TURNS(用户定:放宽) | 找资料 **16** / 备课 **24**,软着陆兜底 | 宁松勿紧,自然终止不费轮 |
| 入口形态 | **CLI 先行**,课表队列接通放 M5 | 先做最难的 agent 本体;入口是薄壳 |
| SVG 类比图 | **不做**,首课只用无资产页型(formula/duo/code/table/quiz) | SVG 生成是独立子问题,记后续增强 |
| write_csl 粒度 | **按页追加** | 上下文可卸载、反馈定位到页、中途崩不丢已写页 |
| agent 图纸 | 照 docs/agent设计.md §三 五维 | 终止靠客观校验,非模型自觉 |

**明确不做(P2 范围外)**:找资料 agent(P3)、SVG 生成、对外版模板(两套模板机制预留,场景参数直达)、多用户。

## 二、任务清单

```
M1 → M2 → M3 → M4 → M5(依赖严格串行)
```

| # | 任务 | 验收标准 |
|---|---|---|
| **M1** | **校验器升级**:进程内 `csl_validator`(错误分 error/warn,报「第X页缺Y」可执行反馈)+「讲到什么亮什么」机械规则;CLI 薄壳化 | 对 harness-01 通过;对构造的坏课件逐条报出可定位错误 |
| **M2a** | **找资料循环** `app/agent/research.py`:`web_search`+`fetch_page`(新)工具;原料=最终 JSON 交付,程序校验**每点必挂来源**,缺源打回;MAX_TURNS=16;trace 落盘 | 真实主题跑一轮,产出原料文件:来源清单可点开、每条要点有源可查 |
| **M2b** | **备课循环本体** `app/agent/prep.py`:工具精选(read_notes+init_course/write_page/validate_csl)+课件作者 prompt(四道闸+页型模板)+24 轮软着陆;吃「备课材料」(原料文件或笔记);来源带进 meta.sources;trace 落盘 | 循环跑通:读材料→逐页写→校验→改→validate 通过自然终止 |
| **M3** | **TTS 编译**:`run_tts` 工具(复用 edge-tts provider),音频路径回填 CSL | 生成的课件每句有音频,播放器可直接上课 |
| **M4** | **端到端验收(主线)**:一条 CLI 命令(`python -m app.pipeline "主题"`):调研→备课→音频→课件;笔记路径同验 | **30 分钟内**:新主题 → 可上课课件(播放+检查点+答疑全链路),meta.sources 可追溯 |
| **M5** | **课表入口接通**:「想学的⬜→调研」「能学的📝→备课」候选池动作 → 后台执行 | 课表点按钮 → 管线跑起来 → 完成后自动出现在「在学的」 |

## 三、边界提醒(施工中必守)

- **vault 只读**(铁律5):备课只 `read_notes`,产物一律落 `ai-classroom/courses/`
- **写工具只进备课清单**(铁律8):`write_csl`/`run_tts` 绝不进答疑 TOOLS
- `meta.source_notes` 必须写回笔记路径——B1 课表靠它把「能学的」挪进「在学的」
- M2 属学习区:动手前先与用户过循环设计(工具 schema/prompt 骨架/上下文策略)
