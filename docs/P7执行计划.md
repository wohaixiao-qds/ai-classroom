## 一、已定决策(2026-11-02 用户拍板)

| 决策点 | 选择 | 说明 |
|---|---|---|
| 大纲的形状 | courses: `[{id, title, goal(可验证行为), why, prereqs(课id DAG), origin}]` + 顶层 domain | 3~8 门;校验器查环/悬空/自依赖/入口课;goal 禁「了解/熟悉」 |
| 旧框架缓存 | subtopics 按需转 courses(顺序即位次,goal 借 why),不报废 | 建议 --refresh 重出带先修链的新大纲 |
| 逐课备课的关联 | depends_on 取大纲 prereqs(人审闸仍可改);承接用大纲前后课 | M2 落地 |
| 大纲可见性 | 生成中心审阅卡(调序/删课/改题→存为领域路线)+课程库领域视图 | M2/M3 落地 |

## 二、任务清单

| # | 任务 | 验收标准 | 状态 |
|---|---|---|---|
| **M1** | **调研出大纲**:框架 prompt 升级为课程大纲设计师(subtopics→courses 带先修链);校验器重写(DAG 环检测/悬空引用/入口课/goal 可验证);legacy 缓存转换;pipeline/CLI 切 courses 字段 | 真主题一句话→真调研出 3~8 门带先修链与可验证 goal 的大纲;校验器单测(合法/环/悬空/自依赖/legacy/数量)全过 | ✅ 2026-11-02:真跑「Agent Harness」3 分钟出 8 门单链大纲,goal 全部可验证,全部源自 vault 足迹 |
| **M2** | **大纲可见可审可点单**:调研任务完成后生成中心展示大纲审阅卡(调序/删课/改题→存为领域路线);每课「备课」按钮→任务队列跑 原料+备课;备课注入大纲位置与 prereqs→depends_on | 从大纲一键备出一门课,自动挂进学习路线;审阅修改落盘生效 | ⏭ |
