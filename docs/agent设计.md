# Agent 设计 · 施工图纸

> 前置：docs/设计方案-v1.md、AGENTS.md（边界铁律 §7/§8）
> 用途：P2 备课 Agent 施工依据；答疑 Agent 现状记录与待修项。
> 定性：项目 5 个角色，仅 2 个是真 agent（带循环+工具）。

---

## 零、什么是「真 agent」

判据一句话：**需要「再决策」→ 用循环（agent）；不需要 → 单次调用。**

- 拿到工具/中间结果后要重新决策下一步 → agent（答疑、备课）
- 一次输入一次输出、无再决策 → 单次调用（复述批改）
- 顺序执行无决策 → 状态机（讲课播放）

| 角色 | 类型 | 理由 |
|---|---|---|
| ④ 答疑 | ✅ agent（已建） | 要多轮决策：查不查/查什么/够了没 |
| ② 备课 | ✅ agent（P2 待建） | 要多轮：读→写→校验→改 |
| ① 找资料 | 备课的子步骤/工具（P3） | 搜→筛→汇总；需自主多轮时才独立成 agent |
| ③ 讲课 | 状态机 | 顺序播放，无决策 |
| 复述批改 | 单次调用（`grader.py`） | 查一次判一次，无再决策 |

## 一、五个设计维度（每个 agent 都过这五维）

```
① 工具(给哪些手)  ② Prompt(岗位说明书)  ③ 循环(手怎么转+终止)
④ 上下文(桌上摆什么)  ⑤ 观测格式(工具结果长什么样喂回)
```

主轴——五维都挂在这根循环链上：

```
模型决策 → 下命令(选工具) → 执行 → 观测 → 回填 → 再决策 → …
   │          │            │      │       │
   ②Prompt    ①工具动作空间  ①工具   ⑤观测   ④上下文
   ③循环                    +错误回收       (回填摆什么/截断)
```

## 二、答疑 Agent（已建，`app/agent/tutor.py`）

| 维 | 设计 | 依据 |
|---|---|---|
| ① 工具 | `web_search` + `read_notes`，**均只读** | 本职是查+答；面对学员任意输入，无写权限 = 砍掉被诱导作恶的门 |
| ② Prompt | 身份（答疑老师）+ 带优先级规范（课件优先→联网→笔记）+ 工具时机 + 底线（查不到就说查不到） | 规范排序给模型确定决策依据；底线放结尾 |
| ③ 循环 | `stop_reason≠tool_use` 停 + `MAX_TURNS=6` 兜底 + 工具错误包成结果回填 | 两道刹车缺一不可；错误是循环输入非终结 |
| ④ 上下文 | 固定底料（身份+课件全文）在前 + 当前页注入 + 历史截 6 轮 | ⚠️ 现有 bug：缓存名实不符（见 §五） |
| ⑤ 观测格式 | 搜索结果 `[1]标题/链接/摘要(截300)`；查不到返回明确文字 | 结构稳定 + 引用锚点 + 失败观测可读 |
| 触发 | 学员提问时实时跑，SSE 流式，轨迹落 `trace` | — |

## 三、备课 Agent（P2 待建，图纸）

| 维 | 设计 | 与答疑的关键差异 |
|---|---|---|
| ① 工具 | `read_notes`（共享）+ `write_csl` + `run_tts` + `validate_csl` | **有写权限，写工具绝不给答疑** |
| ② Prompt | 身份（课件作者）+ 规范核心=「讲到什么亮什么」四道闸 + 按场景选自学版/对外版 + 风格段与答疑共享 | 身份/规范全不同；仅教学风格段共用 |
| ③ 循环 | 读料→写 CSL→校验→不过则改→再校验，终止=**`validate_csl` 通过** 或 MAX_TURNS | **终止靠客观校验，非模型自觉**——能用客观标准终止就别靠模型说了算 |
| ④ 上下文 | 压力最大：整篇笔记+模板+在写的 CSL。对策：分批读笔记、写完一段就落盘（offload）、必要时 sub-agent 隔离子任务（如生成 SVG） | 比答疑重得多，四种上下文手法全用得上 |
| ⑤ 观测格式 | `validate_csl` 报错整理成「第X页缺Y元素」，不抛 traceback | 观测=可执行的反馈，模型得能照着改 |
| 触发 | 下命令时离线跑一次，产出课件文件 | 离线 vs 答疑实时 |

## 四、Agent 间关系

```
共用一个 harness:  app/core/(config+llm) + app/agent/tools.py + trace   ← 一份
各自独立循环:      tutor.py / loop.py(P2)                              ← 平级
文件流水线协作:    备课产出 CSL → 答疑读 CSL，不运行时对话
工具按需精选:      读工具共享点单，写工具只进备课清单
```

不上运行时多 agent 对话（复杂度/观测性代价 >> 收益）；协作靠「文件 + 异步反馈闭环 + 人的判断」。

## 五、答疑 Agent 待修项（代码审查结论）

按严重度：

1. **🔴 上下文缓存名实不符**：`build_context` 注释称「缓存友好」，但把动态的当前页拼进固定前缀、且未加 `cache_control`，缓存实际失效。修法：课件全文独立 system block 加 `cache_control`，当前页挪到 user message。
2. **🟡 MAX_TURNS 耗尽太粗暴**：直接返回「换个问题」丢弃前几轮成果。修法：最后一轮强制不给工具、让它基于已有信息尽量答。
3. **🟡 read_notes 隐私边界未设**：全 vault 全文搜，对外（P5）会暴露私人笔记。自用可缓，对外前必修。
4. **🟢 真流式未做**：SSE 整体跑完才吐 answer（已知债，P4）。
