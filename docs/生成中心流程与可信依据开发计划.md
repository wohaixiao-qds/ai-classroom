# 生成中心流程与可信依据开发计划

本任务经用户批准（2026-11-20），允许 Agent Team 实施。承接现有任务绑定、子进程执行器、证据链与发布门禁，不引入新框架或依赖，不写学习知识库。

## 产品契约

- 输入主题默认生成大纲与首门样课；后续逐课点单沿用现有入口。
- 每项任务展示真实节点：需求与范围、参考调研、大纲、材料、规划、写作、验收修订、发布。不适用的节点明确跳过，历史任务缺记录不得补造。
- 支持停止、继续、删除；已发布课程与学习记录不因删除任务被删除。
- 可信度不设总分。抓取、指纹、摘录定位、结构与交付由程序核验；模型语义审查标明模型及限制；未人工审查如实显示。
- 参考映射若由模型提出必须标明，不将目录映射比例宣称为领域完整度。

## 实施分工

1. 后端任务与恢复：持久化结构化事件、任务详情/停止/继续/删除接口，保留稳定绑定，阻止过期执行回写；隔离测试。
2. 可信依据报告：整合实际大纲来源和发布报告，确定性检查与模型意见分栏，缺失状态明确；隔离测试。
3. 前端生成中心：任务卡与节点详情、可信依据、停止/继续/删除交互；API 类型由 OpenAPI 生成。
4. 主 agent：节点埋点、接口对齐、集成、生成类型、检查与交付。

## 接口约定

- GET `/api/v1/jobs`：任务列表。
- GET `/api/v1/jobs/detail?kind=...&target=...`：任务详情、持久化事件与关联产物。
- POST `/api/v1/jobs/resume?kind=...&target=...`：恢复已有任务。
- DELETE `/api/v1/jobs?kind=...&target=...`：移除任务记录与专属未发布产物，运行中先安全停止。
- 保留 POST `/api/v1/jobs/cancel`、GET `/api/v1/jobs/log` 兼容旧入口。
- GET `/api/v1/jobs/trust?kind=...&target=...`：可核查依据与审查者信息，不返回可信度总分。
- 事件包含序号、执行尝试 id、节点、状态、说明、时间和可选进度；以已持久化事实为准。

## 验收

- 刷新可恢复节点；停止后不能继续发布；继续保留有效产物；删除后旧执行不得复活任务。
- 审查恢复只复用模型、规则与输入未变化的有效结果。
- 来源、摘录与检查报告可追溯，缺项与历史未记录不显示为通过。
- 伪引用、篡改、先修环、缺章节、审查失败等故障路径有测试。
- 后端 unittest、相关 Ruff、前端类型生成/lint/build 通过；界面用隔离数据验证，不触发真实模型或 vault 写入。

## 实施边界

自动来源身份认证与完整参考体系覆盖评估需要可核实的身份记录和目录原文；本轮仅展示已取得的事实，不能用模型声明补齐。未实现的检查明确显示待补充。

## 本轮实现与验收记录（2026-11-20）

- 任务控制：结构化事件落 SQLite；按执行尝试隔离回写；取消立即封锁写入、进程退出前显示“正在停止”；继续复用绑定材料与规划；删除保留墓碑并归档专属未发布产物，保留已发布课程与学习记录。
- 节点展示：调研、材料、规划、逐节写入、最终审查、修订与发布按实际动作记事件；不适用节点显示跳过；历史缺事件不从日志推断通过。
- 可核查依据：来源与摘录、内容指纹、程序核验、具名模型审查分开展示；不设总分、不将模型映射作为完整性认证；报告绑定内容，变化后失效。
- 审查恢复：每批审查后原子保存检查点；输入单项、上下文、模型或提示规则变化时重审对应内容；未完成检查点不能授权发布。
- 离线验证：后端全量 unittest 133 项通过，相关 Ruff 通过，11 个后端模块定向 mypy 通过；前端 CSL 类型一致性、lint 与生产构建通过（存量 lint 与构建体积警告另行保留）。页面以浏览器内模拟接口验证了继续、停止、删除确认、历史缺记录、失效报告、报告请求失败清理及 390px 窄屏无水平溢出，未见浏览器运行错误，不发起真实生成。

### 待后续验证与增强

- 本轮未运行真实模型长任务，不据此声称真实课程教学质量或完整端到端稳定性已验证。
- 来源发布主体身份尚未自动认证；大纲参考映射仍是模型建议，领域完整性与零基础适配不作已验证承诺。
- 当前没有人工审核记录或人工认证结论；模型语义审查可能误判，程序放行仅表示满足已实现规则。
