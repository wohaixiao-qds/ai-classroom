## 二、v2 数据模型设计草案(M0 对齐对象)

```jsonc
// courses/<id>.csl.json · version:2 —— 节→块
{
  "id": "context-compression-memory", "title": "…", "scenario": "自学", "version": 2,
  "meta": { "sources": [], "source_notes": [], "depends_on": [], "duration_min": null },  // 不变
  "sections": [
    {
      "id": "s1", "heading": "为什么要压缩",
      "blocks": [
        {"type": "p", "text": "……"},                                    // 段落,书面 prose
        {"type": "diagram", "lang": "mermaid", "code": "graph TD;…"},   // 示意图,渲染失败降级代码块
        {"type": "code", "lang": "python", "code": "…", "caption": ""},
        {"type": "table", "header": ["…"], "rows": [["…"]]},
        {"type": "callout", "kind": "tip|warn|note", "text": "…"},
        {"type": "quiz", "id": "s1-q1", "question": "…", "pass_rule": "…"},  // 原 checkpoint
        {"type": "flashcards", "cards": [{"front": "…", "back": "…"}]}       // 原 P5·T5
      ],
      "audio": null   // 留位:未来段级朗读 {path, sentences?}
    }
  ]
}
```

设计要点:①文体从口语讲稿改**书面 prose**(备课 prompt 重写,四道闸原则平移);②一节≈原一页的容量(5 分钟读物/课);③quiz 每节至多 1 块,一门课**建议**≥3 节带 quiz——校验器按 warning 提示(写作指引),文件有效性只要求≥1(存量课 function-calling-stability 仅 2 个检查点属合法内容);④块按序即版式,无 fragment/逐步揭示——阅读节奏学习者自控。

## 三、保留 / 退役 / 迁移清单

**保留不动**:catalog+发布(publish_courses)、depends_on 学习路线、掌握度+间隔复习队列(`checkpoint_mastery` 表键语义 page→section,迁移脚本做映射)、答疑 agent+SSE、/grade、三源蒸馏 N1/N2(读课内容处适配节)、三主题 token/Shell/shadcn 组件层、调研缓存(T1)、课表任务队列、traces。

**退役**(代码删除或停用,git 留档):reveal.js+@revealjs/react 依赖、deck 排版类、音画同步引擎(usePlayer 句级 seek)、字幕遮罩、句级步进滑杆、ControlsBar 播放逻辑、o 总览/f 全屏、页导航边栏(改为节目录 TOC)、`?page=N` 深链(改 `?section=N`)、音频编译步骤(pipeline 默认跳过;`tts_compile.py` 代码保留不调用)。

**v1→v2 迁移映射**(存量 8 门课,脚本一次性):页型 cover→首节(标题+meta 表格化)、formula/duo→p(+code)、code→code 块、table→table 块、script 逐句合并为 p 段落(机械合并,口语转书面属可接受损耗,后续人工润色)、checkpoint→节末 quiz 块、`?page=N` 掌握度记录按页序映射到节序(历史不丢)。
